
# Student Records Management System with Database Security

## Project Description
A Java-based Student Records Management System developed for the BIT3360 Advanced Databases group assignment at Zambia University College of Technology.

The project demonstrates database security through authentication, access control, database permissions and SQL Injection prevention.

## Project Objectives
- Store and manage student records.
- Authenticate system users.
- Implement role-based access control.
- Restrict unauthorised database operations.
- Prevent SQL Injection using parameterized queries.

## Technologies
- Java
- MySQL
- MySQL Workbench
- Java Swing
- JDBC
- Git and GitHub
