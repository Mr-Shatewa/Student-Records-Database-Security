## Database Design Documentation

### 1. Database Name
student_records_db

### 2. Table Name
students

### 3. Table Structure

| Field      | Data Type    | Constraints                 | Description |
|------------|--------------|-----------------------------|-------------|
| student_id | INT          | PRIMARY KEY, AUTO_INCREMENT | Unique student ID |
| first_name | VARCHAR(50)  | NOT NULL                    | Student's first name |
| last_name  | VARCHAR(50)  | NOT NULL                    | Student's surname |
| gender     | ENUM         | NOT NULL                    | Student's gender (Male, Female, Other). |
| programme  | VARCHAR(100) | NOT NULL                    | Programme of study |
| email      | VARCHAR(100) | NOT NULL, UNIQUE            | Student's email |

### 4. Primary Key
student_id uniquely identifies each student.
It is automatically generated by MySQL.

### 5. Unique Constraint
The email field prevents duplicate email addresses.

### 6. Sample Data
The database contains five sample student records.

### 7. Database Operations
The database supports:
- INSERT: Register students.
- SELECT: Retrieve student records.
- UPDATE: Modify student information.
- DELETE: Remove student records.

### 8. Technology Used
- MySQL
- MySQL Workbench

## How to Set Up (Local Testing)
1. Open MySQL Workbench (or your MySQL terminal).
2. Run `create_database.sql`.
3. Run `create_tables.sql`.
4. Run `insert_sample_data.sql` to insert the 5 sample records.
